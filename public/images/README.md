# Diretório de Imagens do Sistema SubliGestão ERP

Você pode armazenar nesta pasta todas as imagens locais do sistema:
- `logo.png` (Logotipo da empresa / cabeçalho)
- `favicon.ico` / `icon.png` (Ícone da aba do navegador)
- `catalogo/` (Fotos de produtos, canecas, camisetas, almofadas)
- `mockups/` (Exemplos de sublimação)
- `banners/` (Banners promocionais ou de login)

Qualquer arquivo colocado dentro de `/public/images/` pode ser acessado diretamente pelo sistema pelo caminho:
`/images/nome-do-arquivo.png`
